# License Selection Before Public Release

No license has been selected automatically for this release kit.

Before making the GitHub repository public and archiving V1.0 in Zenodo, choose the license you want others to have.

Two common approaches for a project like this are:

1. **MIT License for the full repository**  
   Simple and permissive. Common for public software repositories.

2. **MIT for code + Creative Commons Attribution 4.0 for documentation/data**  
   More explicit separation between software and non-software artifacts, but requires maintaining separate license notices.

Do not add a license identifier to `.zenodo.json` until you make this choice. Also make sure the GitHub repository and Zenodo record show consistent licensing.

This is a publishing/licensing choice, not a statement about GMP validation or regulatory suitability.
